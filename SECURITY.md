# Security Policy

## Supported versions

Only the latest published version of `eslint-plugin-em-dash-checker` receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub's private vulnerability reporting:
https://github.com/bnap00/eslint-plugin-em-dash-checker/security/advisories/new

You can expect an initial response within 7 days. Once a fix is released, the advisory will be published with credit to the reporter (unless you prefer to stay anonymous).
